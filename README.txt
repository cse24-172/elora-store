ÉLORA STORE — STARTER WEBSITE

FILES
- index.html: page structure and content
- styles.css: colours, typography, layout and responsive styling
- script.js: small demo interactions

HOW TO VIEW
1. Download and extract elora_store_starter.zip.
2. Open index.html in a browser.
3. For editing, open the folder in Visual Studio Code or another code editor.

IMPORTANT BEFORE LAUNCH
This is a visual starter storefront, not a functioning dropshipping checkout.
- Product cards are examples, not verified supplier listings.
- The bag, email sign-up and notify forms are demo interactions only.
- Replace sample imagery with images you have permission to use.
- Verify product quality, supplier reliability, shipping destinations, delivery estimates and returns.
- Configure a supported Botswana/international payment gateway and test it.
- Add real business contact details, policies, privacy disclosures and accurate prices.
- Check domain and business-name availability before committing to the brand.

SUGGESTED NEXT DEVELOPMENT STEPS
1. Confirm the business name and check trademark/domain conflicts.
2. Choose suppliers and obtain landed costs for Botswana and other target markets.
3. Build a product catalogue with accurate prices and shipping.
4. Add cart persistence and secure server-side checkout.
5. Connect payment gateway and order fulfilment.
6. Test the full customer journey before accepting orders.
